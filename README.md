JobCat — AI Resume & Cover Letter Tailoring Tool

Built with Lindy | Personal Project

Overview
JobCat takes a job description as input, automatically tailors a resume and cover letter to match the role, and emails the finished documents back to the user — a working example of requirements-driven automation applied to job searching.

How It Works
- User provides a job description as input to the agent.
- The agent analyzes the role's requirements and rewrites the resume/cover letter to emphasize matching skills and experience.
- The finished, tailored documents are emailed back automatically.
